One funny one-line office joke, in the voice of someone sending a colleague a line after a meeting that should have been an email.

> My keycard opens every door in the building except the one where they decide my salary.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Deterministic: one constant, no network, no randomness, no clock.
